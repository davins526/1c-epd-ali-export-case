# Архитектурный эскиз 1С

**Не production BSL и не точная конфигурация заказчика.** Документ объясняет модульную структуру задачи.

| Уровень | Ответственность |
|---|---|
| Управляемая форма | выбор расчётного периода; таблица соответствий; команды `A`, `L`, `I` |
| Серверные процедуры | параметры периода, выборка исходных данных, сборка логических полей |
| Слой соответствий | автоматический подбор + правка и сохранение пользовательских решений |
| Форматтер | формирование полей в строго фиксированном порядке, сохранение пустых позиций, нормализация строк и денежных сумм |
| Вывод файла | `Windows-1251`, разделитель `=`, доступность файла пользователю |
| Контроль | структурная валидация, количество записей, сверка финансовых итогов, тестовая загрузка у получателя |

**Важно:** публичный Python-валидатор не извлекает данные из 1С и не подтверждает семантическую корректность расчётов. Он демонстрирует только структурный контракт. Частные запросы к регистрами исходной конфигурации в репозиторий не включены.
