# Проверка реализации и ограничения публикации

В исходной задаче последовательно проверяли формирование A/L/I, кодировку, сохранение пустых позиций, значения финансовых полей, выбор видов расчёта и непротиворечивость сальдо по выгрузке. После правок был подготовлен комплект для внешнего контроля. Окончательная успешная загрузка и приёмка принимающей системой в данном кейсе **не утверждаются**.

Не публикуются настоящие файлы, статистика абонентов заказчика, реальные лицевые счета, коды поставщика, его договор, адреса, ФИАС и внутренние запросы базы. Публичные примеры намеренно используют тестовые маркеры.

## Локальные проверки демо

1. Запустить генерацию фиктивных данных.
2. Прогнать валидатор трёх файлов.
3. Запустить модульные тесты.
4. Изменить число полей в строке и убедиться, что валидатор завершится с ошибкой.
5. Удалить пустое поле между `=` и убедиться, что неверное количество позиций обнаружено.
