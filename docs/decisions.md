# Принятые технические решения

- **Внешняя обработка, без изменения клиентской конфигурации.** Настройки соответствий — на уровне пользователя/формы, с автоматическим предложением кодов и ручным уточнением.
- **Структурная выгрузка.** Не пропускать позиции отсутствующих значений: их место в строке сохраняет разделитель `=`.
- **Период.** При построении запросов начало/конец месяца должны быть явными; граница остатков — включающая.
- **Денежная точность.** Выгрузка в копейках, без вычислений на числах с плавающей запятой.
- **Согласование услуг.** Групповая услуга и детализация должны соответствовать согласованным кодам; эти правила не подменяются названием из одной частной базы.
- **Безопасная проверка.** Успешное создание файлов ≠ подтверждённая приёмка в принимающей системе. Сравниваются количества, финансовые остатки и контрольная загрузка.
- **Валидация.** Выделять отдельно структурные ошибки, предупреждения о неполных исходных данных и вопросы, требующие ответа владельца спецификации.
